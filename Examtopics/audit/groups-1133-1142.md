# Q1133–Q1142 独立复核

对照当前题库、原题图及答案图逐题检查每个拖拽来源、目标、分类和组内乱序；原图汇总见 exhibits/contact-groups-1133-1142.jpg。对已修订的交互项，以修订后的题干和文字为准，原图保存为证据。

- Q1133：单模/多模各两槽分别组内无序；光纤分类题干误提 IPv6，修正题干。
- Q1134：四个 IPv6 分类一对一；校验地址和范围，保留对应。
- Q1135：单模/铜缆各两槽分别组内无序；修正无关 IPv6 字样。
- Q1136：四个 IPv6 分类一对一；校验地址和范围，保留对应。
- Q1137：单模/多模各两槽组内无序；长途 DWDM 与短距 SR4 修订符合题意，修正无关 IPv6 字样。
- Q1138：四个 IPv6 分类一对一，目标无显式 id，应用按序号回退；保留对应。
- Q1139：ULA 与 multicast 各两槽组内无序。原“多组织同时使用”也适用于组播，改为限定本地通信的单播特征。
- Q1140：ULA 与 link-local 各两槽组内无序。原“多组织同时使用”不够区分，改为限定本地通信的单播特征。
- Q1141：DHCP snooping 的五种术语一对一。未知服务器不必然未经授权，修改描述并将默认 untrusted 限定到题设平台。
- Q1142：ULA 与 multicast 各两槽组内无序。ULA 的伪随机全局 ID 降低冲突概率，组播源通常为单播但不能排除特殊未指定源情形，保留对应。

依据：RFC 4193 https://www.rfc-editor.org/rfc/rfc4193.html；Cisco DHCP snooping https://www.cisco.com/c/en/us/support/docs/lan-switching/dhcp/97882-dhcp-snooping.html 。该审查不包含真实设备实验。
