# Q1211–Q1220 逐题审查

已直接查看每题题图与答案图并保存至 exhibits；已检查所有拖拽项、目标槽、分类及组内无序标记。未进行真实网络设备实验。

- Q1211：TCP 组：HTTP/1.1、SMTP、Telnet；UDP 组：题设 UDP DNS 查询、RTP 和 SNMP。DNS 同时支持 TCP，区域传送及其他查询可使用 TCP；HTTP/3 使用 QUIC/UDP，因此题设明确具体用法。原解答图将 SMTP 与 DNS 错置，已隐藏；原题图保留供核对。同组内顺序不限。
- Q1212：折叠核心将核心与汇聚功能合并，常用于较小园区，可能减少设备；三层设计有独立核心层连接汇聚块。高可用与冗余取决于具体设计，折叠核心也可使用冗余设备，不能说三层必然更高可用或折叠核心只有一台交换机。已改写原图中含糊描述；同组内顺序不限。
- Q1213：TCP 面向连接，通过序号、确认与重传等机制提供可靠有序字节流；UDP 无连接，协议本身不保证交付或重传，应用仍可自行实现可靠性。原图“无需数据通道”含糊，现改为无需先建立传输层连接。每组内可交换。

- Q1215：2001:db8:600d:cafe::123 和 3ffe:e54d:620:a87a::f00d 落在 2000::/3 地址格式范围；前者是文档前缀，后者是已退役的 6bone 前缀，不能据此推断互联网可达。fe80::a00:27ff:feeb:89aa 是有效链路本地单播；ff05::1:3 为组播地址。两个全局单播格式槽位可互换。
- Q1216：任播地址可分配给多个接口，但报文通常送到路由意义上最近的一个接口；不能说任播只能用于路由器，RFC 4291 已移除旧限制。组播使用 ff00::/8 并可一对多；单播标识单个接口，链路本地及回环属于单播。同组内任意顺序。原题及答案图中的 non-host 专用断言错误，已改写并隐藏错误答案图。
- Q1217：全局单播通常用于可全球路由的地址，类似公网 IPv4，但具体是否可达取决于分配、路由及策略。链路本地仅在链路内有效，路由器不应转发源或目的为链路本地的包。原答案图将公网可路由放入链路本地，且误称接口只可配置一个地址；已改写，修订后的两组各自可乱序。
- Q1218：链路本地地址作用域是单条链路，源或目的为链路本地的包不跨路由器转发。ULA 属 fc00::/7，当前本地分配形式为 fd00::/8，通常不在公网路由；原题“每接口只配置一次”不是通用限制，接口可有多个 IPv6 地址。组内可乱序。

- Q1220：DNS 提供主机名与地址等记录查询；缓存存储先前结果以减少重复查询；resolver 根据请求进行名称查询；域名是层次化命名空间而非可靠地表明组织类型或地理位置。Cisco IOS `no ip domain-lookup` 关闭设备的 DNS 主机名查询，并不等同关闭所有 DNS 服务器或其他 DNS 服务。原图描述过宽，已改写对应标签。
