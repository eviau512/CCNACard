# Q1181–Q1190 逐题审查

- Q1181：已查看题图和答案图；铜双绞线由金属导体与绝缘及护套构成，可使用屏蔽或非屏蔽双绞线。单模光纤用光信号传输，在设计工作波长上支持单一空间传播模式；并非所有光纤都绝对不发生反射，也可通过 WDM 在同一光纤传输多个波长。每组内两项可互换。原答案图沿用过度简化的反射描述，已隐藏；原图留存审查证据。
- Q1182：已查看题图和答案图；多播目的地址标识组，可实现一对多通信；组范围取决于地址的 scope，并非所有组播都能跨链路。链路本地单播的有效范围是该链路，IPv6 动态路由可使用邻居的链路本地地址作为下一跳。两组各自允许组内互换，组播本身也可能具有链路本地范围。原答案图采用了较宽泛的措辞，交互选项已限定。
- Q1183：已查看题图和答案图；铜双绞线可为屏蔽或非屏蔽型，可能受到电磁干扰；适当屏蔽和布线可降低影响。光纤常以玻璃纤芯和包层传输光信号；单模表示在设计波长支持一种空间模式，不表示只允许一个波长，WDM 可承载多波长。两组内部各自无序。原图将 copper 拼成 cooper，并把单模误称单波长，已更正交互文字并隐藏错误答案图。

- Q1185：已查看题图和答案图；金属导体的铜缆可受到电磁干扰，其构造依缆型而异；光纤常采用玻璃纤芯、包层及保护涂层，不受电磁场直接感应。纤芯和包层属于多种光纤的共同结构，不能单凭结构唯一判定单模；组内无序。已修正 cooper 拼写与原图含糊措辞。
- Q1186：已查看题图和答案图；ULA 是用于本地通信的 IPv6 单播，常与私有 IPv4 用途类比；RFC 4193 的本地分配使用伪随机 Global ID 以降低网络合并时冲突概率，但并不保证绝不冲突。IPv6 多播用于一对多，不能作为 IPv6 数据包源地址。组内无序；原图“多组织同时使用”措辞易误解为相同前缀必然无冲突，已改写并隐藏旧答案图。
- Q1187：已查看题图和答案图；AP 提供射频收发，支持特定型号可作为 workgroup bridge；WLC 可集中管理 WLAN QoS 策略并维护客户端信息。PoE AP 可以由兼容 PoE 交换机供电，不必然使用独立适配器；控制器也不是直接放大 Wi-Fi 信号的射频设备。原答案图把这些职责错配，原题还误称配置命令；已更正交互选项与配对，保留题图作为原题证据并隐藏错误答案图。组内顺序不限。

- Q1190：已查看题图和答案图；全球单播地址用于单个接口，地址范围适合全球路由，但能否从互联网访问还取决于路由通告、防火墙及路径；地址类型本身不保证可达。多播目的地址标识一组接收者，可进行一对多发送；IPv6 多播地址不能用于源地址。各类别内顺序可互换。原图把全球单播写成必定互联网可达，已修正互动表述。
