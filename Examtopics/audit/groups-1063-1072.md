# Q1063–Q1072 拖拽分组复核

逐题直接查看已有的原题图及答案图：

- Q1063：五个一对一定义，判分与题图符合；无需乱序组。
- Q1064：四项同属 DHCP 功能，已有单组无序；现有说明已经指出原选项歧义。
- Q1065：认证、授权、记账三组，每组两项可互换，映射正确。
- Q1066：Layer 2 与 WLC Layer 3 Web policy 两组，各自允许交换；映射与图一致。
- Q1067：四个不同攻击的一对一对应，交互判分比旧答案图可靠；隐藏与中间两项矛盾的答案图，原图留证。
- Q1068：用户模式至全局配置的四步存在先后依赖，保持有序。
- Q1069：在设备接入端点断开时，启用端口安全后 sticky、maximum、violation 是独立接口设置，后三项设为同一无序组；原答案图是有效顺序示例。
- Q1070：记账、授权各两项各自可交换；原图的干扰项歧义已在此前修复。
- Q1071：认证、授权、记账各两项各自可交换；题干限定了身份核验语境。
- Q1072：认证、记账各两项各自可交换；修正原图将 PPP 与认证服务器并列的技术误导，并隐藏过时答案图。
