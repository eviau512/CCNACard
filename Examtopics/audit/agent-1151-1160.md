# Q1151–Q1160 审查

逐题检查题干、全部选项、答案、原题图和答案图、解析及代码；按题分类的同组槽位保留 unordered_group。原图接触表见 exhibits/q1151_1160_contact.jpg。

Q1151: 铜缆含导体和护套，常见于办公室接入；单模光纤支持较长距离。单模指传播模式而非只能使用一个波长，原答案图把两类颠倒，已隐藏。

Q1152: ULA fc00::/7 通常不在公共互联网上传播；随机全局 ID 降低站点合并时冲突概率，但不保证零冲突。IPv6 组播以组地址为目的，一般由单播源发送。

Q1153: 此题限定示例：普通网页为尽力而为，VoIP 放入优先队列，数据库同步可整形，视频流按策略监管。实际 QoS 决策取决于业务与策略，监管可能丢弃超额报文；旧答案图错误交换语音与数据库，已隐藏。

Q1154: 铜缆有金属导体与绝缘护套，常用于办公室；单模光纤适用于长距离 DWDM，消除多模光纤的模间色散，并不消除所有色散或衰减。

Q1155: 在题设 API 中 POST 创建子资源，DELETE 请求删除，PUT 替换表示，PATCH 局部修改，GET 获取表示。实际响应及删除语义由服务定义；POST 不保证幂等，PUT 和 DELETE 的预期语义为幂等，但可有日志等副作用。

Q1156: 铜缆可能受电磁干扰，存在被物理接入窃听风险；单模光纤适合高速长距离传输并避免模间色散。距离和速率取决于光模块与链路预算；光纤也可被窃听，链路仍需加密。

Q1157: ULA 通常不在公共互联网上路由；随机生成的全局 ID 降低站点合并时的冲突概率，但不保证零冲突。IPv6 组播向组地址分发，可实现一对多通信。

Q1158: 按修正后的有效示例分类：2001:4860::1 为全球单播，fe80::7 为链路本地单播，ff02::1 为链路本地组播，fd00:382e::3 为唯一本地地址。原图中的 FE80 地址保留位非零、FF00 作用域为保留值；只匹配前缀不足以证明地址有效。

Q1159: 原题拓扑缺失，所附答案图属于上一题，无法确定 VLAN 编号、接口及 R1 所连端口。按现场拓扑创建并命名 SALES VLAN，将 PC3 和 Server1 所连接口设为 access 并分配实际 VLAN；仅在连接 R1 的接口启用 CDP，在其余接口关闭 CDP，验证后保存配置。不要把未经题图确认的端口或 VLAN 数字当作答案。
