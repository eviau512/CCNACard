# Q401–Q405人工审查

逐题读取全部题干/选项/答案/解析，均无图片依赖。下表为修前判断；所有答案字母不变。

| 题号 | 初审 | 依据 |
|---|---|---|
| 401 | 问题 | A可用池正确；DHCP可保存MAC/client-id预留与绑定，不应因D而泛称不保存MAC，DNS也不局限公网。按服务主要职责与转发表区别重写。 |
| 402 | 问题 | D详细IP输出正确；brief的Method也能显示DHCP，接口后brief语法支持不能统一否认。限定完整接口IP属性输出，去固定首行示例及所有平台错误断言，保留D。 |
| 403 | 问题 | C等级0–7全选正确；需已有host/启用日志等前提，阈值不自动启用所有debug命令。B漏Alert1，原解析错说准确覆盖0–4；A低severity语义模糊，改明确only6/7干扰。 |
| 404 | 问题 | B SNMP正确；原模板及乱码没说明CONFIG-COPY-MIB SET写权限、复制操作状态和文件传输协议区别，改具体管理备份机制。 |
| 405 | 问题 | A接口ip address dhcp正确；模板未说明接口模式或client子命令仅参数，补完整配置块及client/relay/server职责。 |
