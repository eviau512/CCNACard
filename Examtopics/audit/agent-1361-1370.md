# Q1361–Q1370 逐题审查

逐题检查题干、各选项、答案、解析、图片和 CLI；本批无拖拽题。原题图 Q1361、Q1366 已直接查看并保留独立证据；均白底蓝色拓扑，暗黑模式需保留颜色，浅色图像画布与放大显示可辅助阅读。
- Q1361：C、E。对于目标地址，路由器对已安装的匹配路由执行最长前缀匹配（E）；图中静态 1.1.1.3/32 与 OSPF 1.1.1.0/24 重叠，目标为 1.1.1.3 时 /32 更长。构建同一前缀的路由时，同一路由协议可以用度量值比较候选路径（C）；跨来源选择还要考虑管理距离和各协议的选路规则，不能把不同协议的 metric 直接比较。图中显示的是不同前缀，并不证明它们仅依据 metric 相互竞争。B、D 选择最高值不符合题设；A 不代表本题通用规则。 依据：https://www.cisco.com/c/en/us/support/docs/ip/enhanced-interior-gateway-routing-protocol-eigrp/8651-21.html
- Q1362：B、C。HSRP 将同一局域网的多台路由器抽象为共享虚拟 IP 和虚拟 MAC 的网关组；活动路由器转发，备用路由器在符合故障检测和选举条件时可接管，以减少网关单点故障。切换并非必然毫秒级或完全无中断，时间取决于定时器和网络环境。A 描述 BOOTP/DHCP 的地址配置；D 为 DHCP 等配置服务；E 错在声称不需要网关，主机仍使用虚拟网关或其他合适路由。 依据：https://datatracker.ietf.org/doc/html/rfc2281
- Q1363：B、C。RFC 1918 地址可用于不需要全球唯一地址的内部设备，从而节省公有 IPv4 地址；不同的隔离网络也可以复用相同地址。网络互联时地址重叠仍可能需要重新编址或转换。私网地址本身不提供网关冗余、互联网连接或安全防护；防火墙、访问策略和互联网出口等需要单独设计。原 C 选项把私有地址当成天然安全层，现改为明确的地址复用优势。 依据：https://www.rfc-editor.org/rfc/rfc1918
- Q1364：C、D。RFC 1918 地址可在彼此独立的私有网络中复用，从而减少对全球唯一 IPv4 地址的需求。若这些网络后来直连，重叠地址可能造成路由歧义，需规划或转换。A 不成立：私有地址可以在企业 WAN 上传递路由，但不应在公共互联网作为全球可达前缀传播。B 私网地址范围有限；E 本身不提供互联网访问，还需要适当的出口及转换等机制。 依据：https://www.rfc-editor.org/rfc/rfc1918
- Q1365：C、D。`fe80::2/64` 是可用于链路本地通信的单播地址；`2001:701:104b:1111::1/64` 是全球单播形式。链路两端通信还需使用相应作用域、兼容前缀与正确接口；题目是分别判断地址类型，并非声称这两个不同作用域地址互为一对。A、B 是组播；E 是用于表示 IPv4 端点的 IPv4-mapped IPv6 形式，不应将它当作普通路由器 IPv6 链路接口地址。原 C 含两个 `::` 且一个字段超过四位，已改成有效链路本地地址；原将 E 作为普通接口答案有误。 依据：https://www.rfc-editor.org/rfc/rfc4291
- Q1366：C、E。对相同前缀的合格候选路由，路由器通常比较路由来源的管理距离，并在同一协议的候选路径中使用该协议的 metric；各协议的具体选路规则仍然适用，不能直接比较不同协议的 metric。图中显示静态 1.1.1.3/32，`[1/0]` 分别为管理距离和度量；图没有展示同一 /32 的所有其他候选，因此题干将比较作为假设。最高 AD 或 metric 不是这里的优选规则。 依据：https://www.cisco.com/c/en/us/support/docs/ip/enhanced-interior-gateway-routing-protocol-eigrp/8651-21.html
- Q1367：B、D。在 Cisco IOS 常见部署中，DHCP relay 配在接收客户端广播的三层接口，可用 `ip helper-address` 将请求转送给远程服务器；这让一个集中服务器能够服务多个子网，但不意味着必须只使用一台服务器或 relay 必须是默认网关。relay 通常填写 `giaddr`，供服务器确定作用域；具体来源地址、转发目的及策略依部署而定。A 的 DNS 参数通常由 DHCP 服务器提供；C 错在限制为一个 helper，同一接口可配置多个；E 错在只依据 MAC 保留项确定子网。 依据：https://www.cisco.com/c/en/us/support/docs/ip/dynamic-address-allocation-resolution/27470-100.html
- Q1368：C、D。Syslog 可以通过 UDP 或 TCP 承载。传统 UDP syslog 常用 UDP 514；TLS 保护的 syslog 使用 TCP，标准端口为 6514，明文 TCP 的端口依实现和配置而定。TCP 的重传和顺序交付不能保证应用、服务器故障或连接中断时每条日志都被持久保存。IP 为网络层，ARP 用于地址解析；RTP 常用于实时媒体，不是此处的 syslog 传输协议。 依据：https://www.rfc-editor.org/rfc/rfc5425
- Q1369：D、E。GetBulk 可在一条请求中请求多项连续变量，降低遍历大表所需的往返次数；响应仍受消息大小、设备实现等限制。Inform 是需要接收方以 Response 确认的通知，与无需确认的 Trap 是不同 PDU；超时可按配置重试，但重试有限且无法保证 100% 送达。Get、GetNext、Set 已在 SNMPv1 使用，分别用于读取、按字典序读取下一项及写入；单次 Get 或 GetNext 也可包含多个变量绑定。 依据：https://www.cisco.com/en/US/docs/ios-xml/ios/snmp/configuration/15-0s/nm-snmp-cfg-snmp-support.html
- Q1370：A、C。按题设通过 IP 访问、使用本地认证建立 SSH，外部 DNS name-server 与 `service password-encryption` 不是 SSH 建立所必需；本地用户、VTY 认证和 RSA 密钥等仍需按平台配置。该题只判断设置 SSH 的必要性，不建议在已有网络中盲目删除安全相关配置：`service password-encryption` 对某些明文口令提供可逆的 Type 7 混淆，关闭前必须评估其他配置。已生成密钥后，删除 domain/hostname 并不必然立即令现有密钥失效；题干明确比较初始密钥生成前提。密钥长度与算法应遵循设备版本及当前安全策略。 依据：https://www.cisco.com/c/en/us/support/docs/security-vpn/secure-shell-ssh/4145-ssh.html
