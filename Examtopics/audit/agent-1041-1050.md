# Q1041–Q1050 逐题审查

- Q1041：A。启用加密的 ESP 隧道模式将整个原始 IP 数据报作为受加密保护的载荷，并增加外层 IP 头；外层地址仍可见。C 混淆传输模式；D 中 TCP/UDP 头在启用加密时属于受保护载荷；B 两种模式并不单凭模式选择决定算法强度，GRE 可按部署使用相应模式。ESP 也支持 NULL 加密或可选完整性，因此题目明确限定非 NULL 加密。 原图及答案图：无。

- Q1042：B。/29 从 /24 借 5 位，得到 32 个子网，每个 8 个地址、6 个可用单播地址，足以给 3 台 PC 和 SVI 网关。192.168.0.1 属于首个 192.168.0.0/29 子网。/30 仅 2 个可用地址；/24 和 /25 分别只有 1、2 个子网。原选项存在空格和无效八位组，已还原成有效 CLI；网关还需 VLAN 存在及 SVI 满足平台启用条件。 原图及答案图：exhibits\q1042_image_agent.png。

- Q1043：图中 Wi-Fi 接口的主机为 192.168.1.20、默认网关 192.168.1.1、MAC 为 B8-76-3F-7C-57-DF；另一虚拟适配器的 1A-76-3F-7C-57-DF 不是该接口地址。/24 的网络地址为 192.168.1.0，广播地址为 192.168.1.255，最后可分配地址为 192.168.1.254。默认网关不必普遍固定为 .1；.20 与 .1 的角色来自图示配置。MAC 不保证始终全球唯一。 原图及答案图：exhibits\q1043_image_agent.png, exhibits\q1043_answer_image_agent.png。

- Q1044：按 AireOS 题设：无线 LAN 控制器管理受控 AP；AP 提供无线与有线网络之间的连接；service port 用于带外管理；virtual interface 支持移动性管理；dynamic interface 将 WLAN 的客户端流量映射到相应 VLAN。具体平台和配置决定端口、管理和转发能力，不能把旧版 AireOS 接口模型套用于所有控制器。 原图及答案图：exhibits\q1044_image_agent.png, exhibits\q1044_answer_image_agent.png。

- Q1045：集中管理用户与 VLAN → Easy Deployment Process；RRM 动态调整功率和信道 → Dynamic RF Feature；控制器向兼容 AP 分发软件 → Easy upgrade process；客户端负载均衡旨在改善用户性能 → Optimized user performance。实际是否自动调整、升级或改善吞吐取决于设备、策略和射频条件，并不保证全网覆盖或最大吞吐。 原图及答案图：exhibits\q1045_image_agent.png, exhibits\q1045_answer_image_agent.png。

- Q1046：四个指定槽位分别为：收到 BPDU 交系统模块、处理并发送系统模块的 BPDU、处理来自相连网段的帧、响应网络管理消息。另一个候选项“Switched frames received from other ports are advanced”也是 forwarding 状态的正确行为，原题只给四槽因而有五项正确，现按题干指定行为消歧；“frames ... discarded”不属于 forwarding。原解答图把 discarde 原图及答案图：exhibits\q1046_image_agent.png, exhibits\q1046_answer_image_agent.png。

- Q1047：本题对应关系为：自治 AP → 通过 Telnet、SSH 或 Web GUI 管理；自治 AP → 使用管理 IP 进行 IP 远程管理。云管理 AP → 云端 Web 仪表盘；云管理 AP → 在满足供电、网络、许可及云服务前提下支持自动部署。WLC 管理通常对应轻量 AP，不能作为自治 AP 的特点。原解答图误将 WLC 管理放入自治 AP，已移除错误解答图；原题图及机器配对保留。管理 IP 也可用于其他 AP 架构，串口本地管理 原图及答案图：exhibits\q1047_image_agent.png, exhibits\q1047_answer_image_agent.png。

- Q1048：本题配对：自治 AP → 管理 IP、通过 Telnet/SSH/Web GUI 逐台管理；轻量 AP → 由 WLC 配置管理、在发现及接入条件满足时支持自动部署。管理 IP 并非自治 AP 独有，云管理和轻量 AP 也会使用 IP；自动部署依赖供电、IP 连通性、控制器发现及兼容配置。不同运行模式也可能用于其他 AP 类型，不能仅凭此项作唯一分类。 原图及答案图：exhibits\q1048_image_agent.png, exhibits\q1048_answer_image_agent.png。

- Q1049：按图配对：ARP 欺骗 → DAI；不希望的更优 BPDU → root guard；PortFast 接口收到 BPDU → BPDU guard；双标记 → 所给选项中 VLAN ACL 对应流量过滤。DAI 常依据 DHCP snooping 绑定或针对静态主机配置的 ARP ACL；root guard 可进入 root-inconsistent，BPDU guard 可令端口 err-disabled。VACL 需平台支持且规 原图及答案图：exhibits\q1049_image_agent.png, exhibits\q1049_answer_image_agent.png。

- Q1050：Telnet 提供明文远程 CLI（默认 TCP 23）；SSH 提供加密远程 CLI 及安全数据传输（默认 TCP 22）；console 是设备物理串口管理；HTTPS 通过 TLS 提供安全 Web 管理（默认 TCP 443）。端口可配置；物理 console 可在设备 IP 网络不可用时管理，但需要设备、线缆及登录权限正常。 原图及答案图：exhibits\q1050_image_agent.png, exhibits\q1050_answer_image_agent.png。
