# Q851–Q860 逐题审查

按 id 核实十题均存在；逐题核对题干、所有选项、答案、解析、图和 CLI。未进行设备实测。

- Q851：修正原选项把私网地址当成天然安全，且 D 并非绝对错误；重写为 RFC1918 唯一定义并更正私网范围拼写。
- Q852：限定内部通信是用途而非仅有用途，移除天然安全和绝对化断言。
- Q853：看原拓扑，补路由和默认 allowed list 条件；恢复各选项 CLI 换行，要求 VLAN 2/10/11/12 均通过。
- Q854：明确同 VLAN 允许转发端口及未知单播条件，修正直通转发与 FCS 绝对化说法。
- Q855：查看原 ipconfig；修正到期与租约仍有效时 T1 单播续订的混淆。
- Q856：查看原图；更正 A 组播 MAC 与 D 重复交换机名，限定同一实例可互通。
- Q857：区分集中配置与 AP 本地有限配置，修正轻量 AP 无状态和职责划分的绝对化。
- Q858：区分逻辑集中和物理分布，移除全部控制功能下移和必须 ASIC 等绝对化。
- Q859：说明 RRM 可缓解但不保证消除干扰，避免对 WLC 平台功能作绝对断言。
- Q860：限定 AireOS 多接口及已选控制器阶段，补证书、可达性和平台边界。
