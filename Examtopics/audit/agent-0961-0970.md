# Q961–Q970 逐题审查

- Q961：C。SSID 是无线服务集的名称标识，区分大小写，长度上限为 32 字节，并不等同 32 个任意字符。A 文件共享依赖应用与网络策略；B 和 D 需要端点防护、认证及加密，SSID 本身不提供这些能力。隐藏 SSID 也不能替代认证。

- Q962：C。配置 RADIUS 服务器 IP 等连接参数，并在 WLAN 上启用 Allow AAA Override，可让控制器应用服务器返回的授权属性，例如动态 VLAN。AAA Override 不是所有普通 RADIUS 认证都必需，题干限定动态授权；还需共享密钥和可达性。A/B 的 SSH 不承担客户端 RADIUS 认证；D 的服务器 MAC 不替代服务器 IP，802.1X 则是企业认证机制。

- Q963：C。restrict 在安全 MAC 数达到限制后丢弃未知源地址帧，保留端口并记录违规、递增计数；配置相应 SNMP 通知后可发送 trap。protect 不产生同样通知；shutdown 使端口 err-disabled；shutdown VLAN 针对违规 VLAN，实际支持依平台而定。

- Q964：A。ESS 通过分配系统连接多个 BSS，共用 SSID/ESSID 的 AP 可为客户端呈现相同网络名称。相同名称不保证共享二层网络、无缝漫游或会话不中断，还需匹配安全、网络与客户端条件。B 的 802.11k/v/r 是另外的能力；C 描述 BSSID；D 名称本身不提供额外加密。

- Q965：A。集线器在物理层将输入信号重复到其他端口，并不查询 MAC 表；交换机按同一 VLAN 的目的 MAC 表项转发到相应可转发端口。B 的 FIB、C 的 MAC 和路由表不属于普通集线器；D 颠倒两者。组播可能受侦听机制约束，并非总对所有端口泛洪。

- Q966：B。图中四台交换机连通并参与同一 STP 实例。SW1 与 SW2 的优先级 20480 小于 SW3、SW4 的 57344；两者比较桥 MAC，00:10:a1:54:4e:50 小于 00:10:a1:71:e3:35，因此 SW2 的桥 ID 最小。系统扩展 ID 对同一实例相同；不同实例需分别选根。

- Q967：D。原图直接显示 txload 和 rxload 都是 255/255。图中 100 Mb/s FastEthernet 同时显示 200/230 Mb/s 和每秒 40 包，数据彼此不合理，因此不能据此证明真实硬件饱和或故障根因。累计 267 个广播和零错误也不足以排除或证明其他故障；应检查真实设备、速率与时间序列。

- Q968：A。图中把 10.90.207.87/26 写作路由前缀，但它有主机位，规范网络地址为 10.90.207.64/26；题设明确将四条视为候选路由，而非声称均已同时安装。两条 OSPF 的管理距离 110 低于两条 RIP 的 120；在 OSPF 中 1912 小于 28968，因此选 F0/7。跨协议 metric 单位不同，不直接比较。

- Q969：D。虚拟机通过 hypervisor 分享主机硬件资源，包括 CPU、内存和 I/O；资源调度、隔离和分配取决于平台。B 的物理网络接口也可以共享，但仅是其中一类；A 外部存储可被共享却非必须；C 不概括主机资源。

- Q970：D。RFC 1918 定义 10/8、172.16/12、192.168/16，可在不同私网重复使用，不作为全球唯一公共地址路由。私网地址不是安全屏障，网络仍可能通过 NAT、代理、VPN 等连接；防火墙外部接口也可能使用私网地址。A/B 误称全球唯一或全球可达；C 错把地址类别当访问控制。
