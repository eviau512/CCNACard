# Q781–Q790 逐题审查

逐项检查题干、选项、答案、解析、展图及 CLI；实际设备未测试。

- Q781：C。先在支持封装选择且默认 negotiate 的平台指定 dot1q，再设 trunk 与 allowed vlan 1-10；两端配置须兼容。B 未明确选择封装且 native 11 不在允许列表；A 没有显式选择标准封装且聚合无关；D 使用 Cisco ISL。只限制题设用户 VLAN，部分控制协议可能仍在 VLAN 1 交换；仅支持 dot1q 的平台可能没有 encapsulation 命令。
- Q782：C。图中 Full Duplex、10000 Mbps，累计 collisions 为 8662416065，计数器从未清零；单张快照无法证明数值何时增加或确定原因。检查平台/驱动计数器含义、软件版本与对端链路，并在记录基线后观察增量，结合 CRC、丢包、接口及流量排查。全双工万兆链路不应直接假设对端回退半双工；5 分钟平均速率与零累计 output drops 也不能排除短暂拥塞。原题把巨大计数直接归因双工不匹配，证据不足。
- Q783：A。图示 R2 MAC 为 12-a0-ab-cc-00-01；首字节异或 02 得 10，中间插入 ff:fe，接口 ID 得 10a0:abff:fecc:0001，与 2001:db8:d8d2:1009::/64 拼接为 A。B 未正确翻转首字节及第二字节，C、D 的接口 ID 也不符合。若在 IOS 生成地址，应按平台支持使用 `ipv6 address 2001:DB8:D8D2:1009::/64 eui-64`；图中标示的 MAC 需确为所配置 LAN 接口使用的地址。
- Q784：B。Syslog severity/level 表示事件严重程度，0 为 Emergency、7 为 Debug；服务器可依级别规则将消息写入不同文件。facility 表示消息类别或来源，message body 是文本，process ID 标识进程，均非题目所求级别。Cisco 消息中的 FACILITY 标签与 RFC syslog priority 中的 facility 术语相关但不是简单一一对应；服务器过滤与文件去向取决于具体配置。
- Q785：B。AireOS 管理接口用于控制器带内管理，并通常承担轻量 AP 的发现与控制通信。console 是本地串行管理，service port 用于带外维护，virtual interface 用于部分客户端相关功能。具体 AP-manager 接口、端口与软件型号可影响部署，不能把默认设计说成所有 WLC 的唯一实现。
- Q786：B。0.0.0.0/1 和 128.0.0.0/1 分别匹配目的地址的两半，优先于 /0；两条 /0 作为更不具体的备用。链路失效时在题设明确的下一跳撤销条件下，受影响的 /1 与对应 /0 撤销，另一条 /0 可承载流量。实际分流量不保证 50/50；单靠静态路由未必发现上游故障，递归解析及 IP SLA/track 等需按设计处理。C 为等价默认路由但不按最高位拆分；D 没有备份 /0；E 仅主备；A 的 AD 255 不可安装且缺对另一半的有效主路由。原题同时把 C、D 当成两个必须共同配置的答案，与冗余条件不符。
- Q787：C。图示原 group 2 为 PAgP；清除不兼容旧配置后，物理成员接口 `channel-group 2 mode active` 使用 LACP，另端需支持并兼容 active 或 passive，成员配置须匹配。A/D 在逻辑接口上配置成员且是 PAgP 模式；B 是静态 on，可与兼容静态聚合互通但不进行 LACP 协商，故不满足题设。组号为本地标识，不必与对端相同。
- Q788：A。Cisco 的 AireOS 部署指南通常推荐交换机对发往 WLC 的流量使用 source-destination IP 哈希。多个不同源/目的 IP 组合有助分散流，但成员选择取决于设备、流量和哈希实现；单流一般仍落在一条链路上，均匀分配并无保证。仅使用目的 IP 在大量流都指向同一 WLC IP 时可能集中；MAC 哈希效果也取决于二层路径和 MAC 分布。
- Q789：D。802.11a 工作在 5 GHz，通常比 2.4 GHz 的 802.11b/g 有更多可用不重叠的 20 MHz 信道，适合需要更多信道的规划；实际数量受地区法规、设备及 DFS 限制。A 成本受设备和部署影响；B 所述 2.4 GHz 干扰源并非 802.11a 的同频干扰；C 单一 802.11a 无线电不直接兼容 2.4 GHz 的 b/g，但双频设备可以分别支持。更多信道不保证消除干扰。
- Q790：A。两端采用 dot1q trunk，允许业务 VLAN 100 和 105，并将两端 native VLAN 设置为 3。VLAN 3 未列入 allowed 列表，因此不能据此宣称普通 native VLAN 数据可在该链路通过；题设明确无需此类流量。B 使用 ISL 且 native 仍为 1；C/D 的 access vlan 不能一次指定多个 VLAN，D 也不是 trunk。更换 native VLAN 是安全加固的一部分，不能单独保证阻止所有 VLAN 攻击；部分控制流量有平台特定行为。
