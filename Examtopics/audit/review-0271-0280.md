# Q271–Q280逐题语义审查

人工读取题干/全部选项/答案/解析，4张原图直接查看。下表保留修复前判定；无模板长度阈值或自动批准。

| 题号 | 原答案 | 初审 | 核验与修订 |
|---|---|---|---|
| 271 | C | 问题 | C意图为默认OSPF cost，但单个出口除法不等于整条路径累计cost；接口bandwidth配置值也非实时实际吞吐。未限定同类OSPF路径，不能把所有类型一律只比cost。补Cisco默认、同前缀intra-area路径，C写接口cost累加；删协议永远追求最高带宽的保证。 [S1][S2] |
| 272 | D | 问题 | D/备份AD更高正确；原解析保证主链路物理故障后备份立刻接管，忽略主路由可能未撤回及备份下一跳有效性，AD255还不入表。明确同一完整前缀/主路由撤回/备份仍可用；解释高于主但小于255和必要时追踪，不承诺零延迟。 [S3] |
| 273 | C | 问题 | 已看图Hello10/Dead40、Neighbor Count3/Adjacent3，C正确。原解释把point-to-multipoint也算默认10/40、从邻居3推出整个OSPF域仅4台，且残留多次转义amp实体及损坏URL。重写局部链路证据；DR/BDR不单独排除NBMA，不能泛称见DR必broadcast。 [S2][S4] |
| 274 | C | 问题 | C默认Ethernet broadcast正确，开头一句有效但后续四选项全为无差别模板，未说明物理两节点也不自动变point-to-point、另外类型与介质/显式覆盖的区别。用简洁具体机制替换模板，限定Cisco IOS普通routed GigabitEthernet默认。 [S4] |
| 275 | C | 问题 | C正确意图为同前缀跨协议AD，但同destination未明确相同掩码；逐项模板也没说明DUAL/EIGRP、metric与RIP hop count的区别。补完整同前缀且有效候选，重写入表与LPM阶段区别。 [S5] |
| 276 | B | 歧义 | B/90仅适用于默认内部EIGRP；若EIGRP是外部重分发AD170，则OSPF110胜。原题未限定internal/default AD，解析将全部EIGRP都说90。补相同完整前缀、内部EIGRP与默认AD，再解释A20=eBGP/C110=OSPF/D115=IS-IS。 [S5] |
| 277 | D | 问题 | 已看图现O10.10.13.0/25 [110/2] via10.10.10.1 Gi0/0，若新eBGP同前缀有效且默认AD20，应该新路经Gi0/1入表，C而非标D；原英文也支持C但模板反说D。原图last-resort头10.10.11.2又与底行静态via10.10.10.1矛盾。重绘明确相关初始路由/拓扑的练习图，答案改C，不推断回程不对称。 [S5] |
| 278 | D | 问题 | 已看图：只有O10.10.13.0/25经Fa0/1与Fa0/2等价路径，覆盖.0–.127；目标.128/25不在其中，且无last-resort。D方向正确，但逐项解释全模板、未解释已显示的ECMP为何不适用于另一半子网。保留D，具体写无匹配/无默认、ECMP只针对已有前缀。 |
| 279 | B | 问题 | B的共享VIP/虚拟MAC正确，v1/v2模式也正确；但解析说Standby必须通过抢占机制接管失效Active，混淆故障接管与高优先级夺回，且普通泛洪不必然广播风暴。明确hold超时等触发接管不以preempt为前提，preempt用于现Active仍在时主动取代。 [S6] |
| 280 | A | 问题 | 已看R1 Hello10/Dead40、R2 Hello20/Dead80，Area1/Broadcast/priority1同类，RID不同正常，A意图需同时匹配Hello和Dead。原问题要求只邻居不邻接，与两节点可选DR/BDR后形成Full不符；单改Hello也不证明Dead一致。改问修复显示的阻碍，A明确匹配两计时器，删无证据官方标准答案/历史背景说法。 [S2] |
