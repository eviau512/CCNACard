# Q741–Q750 逐题审查

审查题干、全部选项、答案、解析、图和 CLI。原图 Q742、Q744 已直接查看；答案不变。

- Q741: 限定 Type 7 的支持范围和可逆性。
- Q742: 修正 secret 选项误录，明确要求 secret 哈希以消除 Type 7 选项歧义。
- Q743: 消除关于检测和人员授权的绝对化说法。
- Q744: 补账号 privilege 15 使登录立即完整权限；还原 CLI 换行并标注 Telnet 风险。
- Q745: 更正 RSA 签名和密钥性质。
- Q746: 限定 PMF 的防护范围，避免声称完全免疫。
- Q747: 修正强制特殊字符和必须最长的错误建议。
- Q748: 限定为所列算法比较；区分口令质量和哈希强度。
- Q749: 纠正公钥密码不能自动验证公钥身份。
- Q750: 避免防病毒必然阻止零日及所有攻击的断言。
