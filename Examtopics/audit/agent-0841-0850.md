# Q841–Q850 逐题审查

本范围缺少 ID 848：现有题库 ID 并非完全连续，实际审查9题；未改题号。

- Q841（Q1129）：图中最后数组元素有尾随逗号，不是严格合法JSON；port是名称。
- Q842（Q1131）：半双工计数119只能证明曾发生碰撞，不能仅凭此断定双工不匹配。
- Q843（Q1133）：核对客户端接口及中继地址，保留A，补服务端地址池和回程前提。
- Q844（Q1136）：原选项重复SW4且出现组播MAC，改正标签并将05首字节改04以得到单播BID。
- Q845（Q1138）：加密不阻止捕获信号；修订D使其描述机密性而非防截获。
- Q846（Q1139）：原题缺失路由表与目的地址，无法推出答案；补入明确标注的自包含示例。
- Q847（Q1140）：区分IPsec封装模式与加密是否启用，避免称整个IP报头总是加密。
- Q849（Q1143）：SSID是服务集标识，不保证独占VLAN、安全认证或必须被广播。
- Q850（Q1145）：图中地址文本存在异常，各行像候选而非同一已安装路由表；限定为相同前缀候选路由。
