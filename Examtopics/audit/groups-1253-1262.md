# Q1253–Q1262 独立复核

逐题阅读题干、全部选项、答案及解析；十题均无题图、答案图、拖拽或代码。

- Q1253：B/D：两种符合规范的 Cat 5e、Cat 6A 信道均支持 100 米 1000BASE-T；C 的 55 米上限与题设不符。
- Q1254：C/D：交换转发可执行 VLAN 标签处理和目标 MAC/VLAN 查表；NETCONF、路由协议及设备本机 ICMP 均非题设转发帧操作。
- Q1255：B/E：SSID 最多 32 字节，信标发布可配置；不单独构成安全机制。
- Q1256：A/E：题设启用广播，信标通告 SSID，32 字节上限；不限定单 AP 或控制器。
- Q1257：B/D：打印机与 AP 属常见接入层连接；三层边界/冗余不是唯一分层证据。
- Q1258：A/B：IPv6 可访问 IPv6 目标、私网 PAT 可共享公网 IPv4；v6-only 访问 v4-only 需要其他机制。
- Q1259：B/C：独立网络复用 RFC1918 地址，私网前缀不需进入全球公网路由；互联重叠须规划，私网不加密。
- Q1260：A/C：限定支持 802.3bz 且信道合规，Cat 5e 和 Cat 6A 可用于对应 2.5/5G 铜缆链路，光模块及电话线不符合。
- Q1261：B/E：RFC1918 内部编号可独立 ISP 前缀，复用减少公网地址需求，合并重叠时有转换或重编号风险。
- Q1262：C/D：AireOS 创建页分别配置 Profile Name 与 SSID，WLAN ID 另选；Cisco 配置步骤与题干一致。

AireOS 创建页参见 [Cisco 文档](https://www.cisco.com/c/en/us/support/docs/wireless-mobility/wlan-security/115951-web-auth-wlc-guide-00.html)；私网行为参见 [RFC 1918](https://www.rfc-editor.org/rfc/rfc1918)。未作实机实验。
