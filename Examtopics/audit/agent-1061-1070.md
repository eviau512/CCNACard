# Q1061–Q1070 逐题审查

- Q1061：命令匹配：`show snmp host` 显示配置的通知接收者；`show snmp engineID` 显示本地以及已配置远端 SNMP 引擎标识，部分平台同时显示远端 IP；`show snmp group` 显示组及安全模型；`show snmp community` 显示 community；`show snmp chassis` 显示已配置的 chassis ID（题图称序列号）。具体输出与平台、配置有关，engineID 不是自动发现所有远端设备的地址；chassis ID 不保证总是硬件序列号。

- Q1062：分类依据描述符字段划分类；CBWFQ 是 **class-based weighted fair queueing**，在配置且平台支持时为指定类在拥塞时提供带宽保障；整形通过缓冲平滑输出，不能保证杜绝下游拥塞；监管依限速规则丢弃、重新标记或传送超额流量；资源竞争可能引起拥塞。原图误写 cloud-based，答案图中 policing 与 CBWFQ 的目标也对调；请以修正后的交互标签及配对为准。

- Q1063：检测（fault detection）发现性能下降或中断；关联聚合把相关告警归组；诊断隔离定位可能的原因；解决（problem resolution）可由管理员消除故障源；恢复服务可以执行预置脚本恢复功能。自动关联不保证找到根因，恢复也未必代表根因已被永久消除。原题是通用故障管理流程，系统可利用 SNMP，但不是所有步骤均由 SNMP 本身实现。

- Q1064：四个正确项是维护地址池、基于客户端/服务器的网段控制、减少终端上线的手工配置、按可配置租约分配地址。DHCP 也可以通过 option 6 向客户端提供 DNS 服务器地址，因此原图中的 “offers domain name server configuration” 也是有效功能；为使四空唯一，交互项改为运行权威 DNS 名称解析。域名与地址的记录解析及权威 DNS 区域服务属于 DNS；DHCP 能分发 DNS 配置但不等于自身提供权威解析。租约和 relay 的行为取决于服务配置。

- Q1065：认证验证身份：标识用户并校验凭据；授权决定允许执行的操作及可用服务；记账记录会话及操作以供管理员分析。每组内两个空可互换；实际是否记录命令或其他字段取决于配置，不能假定所有活动都会自动留痕。

- Q1066：按 Cisco WLC 的配置分类，WPA/WPA2 和 802.1X 属于 Layer 2 配置；web policy 与 passthrough 在该题的 Layer 3 Web 策略类别中。同组答案可交换。802.1X 是端口访问控制框架，WPA/WPA2 为无线安全机制；Web passthrough 可能只要求接受条款，不能等同于验证用户身份，也不能保证空口加密。具体组合取决于控制器软件。

- Q1067：双标签攻击：避免将用户接入口放进 trunk 所用 native VLAN，并采用专用未用 native VLAN；仅更改默认 VLAN 编号不自动防御。MAC flooding：802.1X 限制未授权设备接入，仍需结合端口安全和限制，不能保证已认证设备不会发送大量伪源 MAC。DHCP snooping 可阻挡非信任端口伪 DHCP 响应，从而缓解该类中间人；不能单独阻止所有 ARP 欺骗，可结合 DAI。禁用 DTP、将接入口显式配置为 access 可降低交换机伪装协商 trunk 风险。原答案图将中间两项对调，以交互配对为准。

- Q1068：从 User EXEC 依次 `enable` → `configure terminal` → `enable secret $hf!@4fs` → `exit`。题目假定已具备进入特权模式的权限；`enable secret` 配置的是特权口令散列而非可逆加密，具体类型由平台和配置决定，旧类型可能不安全。`service password-encryption` 是可逆的 Type 7 混淆，不能替代 secret；`line vty 0 4` 是线路配置。

- Q1069：假定接口已经处于 access 模式：启用 port-security、启用 sticky 学习、设置最多两个安全源 MAC、将违规动作设置为 shutdown。Sticky 将动态学习到的地址加入运行配置；持久化需保存配置，变化的设备可能触发违规。shutdown 在违反安全源 MAC 规则时使端口进入 err-disabled；它限制不同源 MAC 数量，不是对广播、多播或未知单播的流量速率限制。阻止高流量风暴还需依平台配置 storm control。

- Q1070：记账可记录远程会话时长并经 TACACS+ 记录管理命令；授权可对所支持的 RADIUS 用户网络服务授权，也可限制 CLI 命令。每组两项顺序可交换。原题干扰项 “user- or group-based access” 也可描述授权，导致授权项不止两个；交互选项改为验证凭据，使题目唯一。实际协议支持及命令授权能力依设备而异，验证凭据属于认证。
