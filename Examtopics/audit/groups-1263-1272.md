# Q1263–Q1272 独立复核

逐题核对题干、全部选项、答案、解析及图/CLI；直接查看 Q1264 原图，其余无图。

- Q1263：核对二层与三层命令、两种 LACP 状态及 C/D；物理成员前提明确。
- Q1264：直接查看原图，Po10(SU) 为 LACP 且 Gi0/0、Gi0/1 均为 P；不同模式 active/passive 可协商，A/C 合理。
- Q1265：默认 VLAN 是交换机数据库的默认项；修正 VTP 描述，保留 B/C。
- Q1266：核对 CDPv2 可通告 native VLAN 和 VTP 域，A/C 合理；不是完整 VLAN 数据库。

- Q1268：主动模式 PAgP desirable 与 LACP active 正确；澄清在成员物理接口输入命令。
- Q1269：同域名及题设同版本 A/E 合理；静态 trunk 不要求 DTP。
