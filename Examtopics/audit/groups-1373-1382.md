# Q1373–Q1382 独立复核

逐题核对题干、全部选项、答案、解析、图和CLI；没有发现需要再修改的问题。Q1373 原图已直接查看。

- Q1373：图示为 Gi0/1 access 且 port-security 已启用；sticky 学习写入运行配置，restrict 丢弃违规并记录，答案 A/E 成立。 来源：https://www.cisco.com/c/en/us/td/docs/switches/lan/catalyst2960x/software/15-2_7_e/configuration_guide/b_1527e_consolidated_2960x_cg/configuring_port_based_traffic_control.html
- Q1374：ESP/AH 是 IPsec 保护协议；3DES/AES 是算法，TLS 不是 IPsec 保护协议，C/E 成立。
- Q1375：WPA3-Enterprise 可选 192-bit 套件采用 GCMP-256；WPA3-Personal SAE、WPA2-Personal PSK，C/D 成立。 来源：https://www.cisco.com/c/en/us/support/docs/wireless/catalyst-9800-series-wireless-controllers/220712-configure-and-verify-wi-fi-6e-wlan-layer.pdf
- Q1376：题干分别限定动态 spoke 与私有 WAN 组加密，DMVPN/GETVPN A/B 成立；其他是泛称或远程接入。
- Q1377：在接口实际由控制器提供的前提下，REST/SOAP 均可作北向 Web 接口，A/C 成立；接口方向取决于部署。
- Q1378：GET/POST 是标准 HTTP 方法，REMOVE/REDIRECT/POP 不是通常核心方法，C/D 成立。
- Q1379：PATCH 与 PUT 在常见映射中支持更新，具体 API 也可能用 POST；题目限定常见映射，A/E 成立。
- Q1380：Cisco AireOS 8.7 文档明确 service-port 支持 SSH/Telnet，排除 TACACS+/RADIUS，列表未列 SCP，A/D 成立。 来源：https://www.cisco.com/c/en/us/td/docs/wireless/controller/8-7/config-guide/b_cg87/m_ports_and_interfaces.pdf
- Q1381：10.172.76.200 属 10/8，172.31.255.100 属 172.16/12；其余不属于 RFC1918，A/D 成立。 来源：https://www.rfc-editor.org/rfc/rfc1918
- Q1382：接入终端 PortFast 加速 forwarding，正常边缘端口上下线不产生相应 TCN；不禁用 STP 或限制 MAC，B/D 成立。 来源：https://www.cisco.com/c/dam/en/us/support/docs/switches/catalyst-6500-series-switches/24330-185-01.pdf

本复核基于静态题图及文档，未在网络设备实测。
