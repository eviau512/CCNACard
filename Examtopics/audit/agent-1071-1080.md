# Q1071–Q1080 逐题审查

每题均直接查看原图与答案图，检查题干、全部拖拽来源、目标、答案、解析及代码需求。未做设备实测。

- Q1071：Accounting：记录会话统计和用户执行的命令；Authentication：验证用户凭据、核实尝试访问路由器的身份；Authorization：决定用户权限，包括是否允许进入 enable 模式。
- Q1072：Accounting：记录用户消耗的网络资源、跟踪所用服务。Authentication：核验凭据并接受或拒绝登录尝试，可使用本地数据库、RADIUS 或 TACACS+；PPP 可使用相关认证协议，但 PPP 本身不是 AAA 服务器。
- Q1073：Security policy 是规定组织安全目标、职责和基本要求的政策；security standard 具体规定必须遵守的统一要求。Awareness 让全员关注并理解基本安全事项；training 培养岗位所需操作技能；education 深入学习跨领域概念和原则。
- Q1074：DHCP snooping：拦截不可信端口上的非法 DHCP 服务器响应；DAI：按 DHCP snooping 绑定或配置的 ARP ACL 验证不可信端口 ARP；storm control：按配置阈值限制对应广播、组播或未知单播流量；IP Source Guard：依据绑定过滤来源 IPv4 地址，可按平台与配置另外检查源 MAC。
- Q1075：此题设示例中控制器方案以网络与策略为中心并使用允许列表；传统方案以设备配置为中心并使用阻止列表。同组空位可互换。
- Q1076：Ansible：通常通过 SSH 无代理管理网络设备，playbook 使用 YAML。Chef：常见 recipes 和 cookbooks 使用 Ruby DSL；题目所述旧版 Chef Push Jobs 服务可使用 TCP 10002，该端口不是所有 Chef 配置管理部署的通用端口。Puppet：使用 manifest 描述配置，agent 与 Puppet Server 默认通过 TCP 8140 通信；端口可更改。
- Q1077：题设中的 DNA Center 示例包括检查云端软件更新、使用 CLI 模板批量部署及结合 NetFlow 遥测与相关安全分析平台。传统示例是逐设备 SSH、逐设备维护配置和以边界设备为主的安全管理。
- Q1078：Accounting 记录用户或会话活动；authentication 验证身份；authorization 验证和决定访问权限；CoA（Change of Authorization）可在已建立的会话中请求更新授权属性。
- Q1079：多租户是多个租户共享基础设施并实施隔离；scalability 指资源随负载扩缩；workload movement 指将工作负载迁移到其他位置；on-demand 指按需申请资源；resiliency 指故障后维持或恢复服务的能力。
- Q1080：按题设，控制器方案集中配置资源、提供 API 及集中可视化；传统方案逐设备配置，且本示例使用分布式控制平面。
